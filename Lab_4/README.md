# Лабораторная работа №4: Линейные модели классификации и регрессии: аналитическое и итеративное решение

## Описание датасета

Используется датасет **Medical Cost Personal Datasets** (файл `insurance.csv`). Он содержит данные о клиентах медицинской страховой компании. Пропусков в данных нет.

|   Признак  | Описание                                                       |
|------------|----------------------------------------------------------------|
| `age`      | возраст клиента                                                |
| `sex`      | пол (`male` / `female`)                                        |
| `bmi`      | индекс массы тела                                              |
| `children` | число детей, покрытых страховкой                               |
| `smoker`   | статус курильщика (`yes` / `no`)                               |
| `region`   | регион проживания (northeast, northwest, southeast, southwest) |
| `charges`  | индивидуальные медицинские расходы (целевая переменная)        |

Источник данных: https://www.kaggle.com/datasets/willianoliveiragibin/healthcare-insurance

## Краткие выводы

**Качество моделей.**
- Логистическая регрессия значительно лучше случайного угадывания: подавляющее большинство клиентов относится к верной группе. Ошибки возникают в основном рядом с порогом вероятности 0.5, где классы трудно разделить.
- МНК и SGD дают практически одинаковое качество по RMSE и R². SGD сходится к тому же решению, что и МНК, во многом благодаря масштабированию признаков.
- На небольшой таблице МНК работает быстрее SGD. Преимущество градиентного спуска проявляется на очень больших данных, где матричные вычисления становятся слишком дорогими.
**Интерпретация весов.** Признаки стандартизированы, поэтому веса можно сравнивать по силе влияния.
- **Сильнее всего повышают расходы:** статус курильщика (`smoker`), с большим отрывом от остальных, затем возраст (`age`) и индекс массы тела (`bmi`). Число детей (`children`) даёт лишь небольшой положительный вклад.
- **Тянут расходы вниз:** небольшие отрицательные веса у регионов (`southwest`, `southeast`, `northwest`). Вес признака пола (`sex`) близок к нулю, то есть при прочих равных пол почти не влияет на расходы.
