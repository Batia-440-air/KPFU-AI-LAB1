# Лабораторная работа №1. Введение в машинное обучение и подготовка данных

## Описание датасета

В работе используется датасет **Bank Marketing** (файл `bank.csv`). Он содержит данные о клиентах банка, которым по телефону предлагали открыть срочный депозит. В таблице 11162 клиента и 17 признаков, пропусков нет.

Признаки:

- данные о клиенте: возраст (`age`), профессия (`job`), семейное положение (`marital`), образование (`education`);
- финансовое положение: баланс на счёте (`balance`), наличие просрочки по кредиту (`default`), ипотеки (`housing`) и потребительского кредита (`loan`);
- данные о контактах: способ связи (`contact`), день (`day`) и месяц (`month`) последнего звонка, длительность звонка (`duration`), число контактов в этой кампании (`campaign`), число дней после прошлой кампании (`pdays`), число контактов до этой кампании (`previous`), результат прошлой кампании (`poutcome`);

Источник данных: https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset

## Постановка бизнес-задачи

Банк проводит телефонную кампанию по продаже срочных депозитов. Обзвон всех клиентов подряд требует много времени и денег, а часть клиентов в любом случае откажется. Необходимо по данным о клиенте предсказать, откроет ли он депозит. Это задача бинарной классификации.

Результат модели позволит заранее ранжировать клиентов по вероятности согласия и обзванивать в первую очередь тех, у кого она выше. Это снизит нагрузку на колл-центр и повысит долю успешных звонков при том же бюджете.

## Описание пайплайна

**1. Настройка окружения.** Импортируются библиотеки: `pandas` для работы с таблицами, `matplotlib` и `seaborn` для графиков, из `sklearn` берутся `train_test_split` для разбиения данных, `StandardScaler` для масштабирования, `RandomForestClassifier` как модель и `accuracy_score` как метрика качества.

**2. Загрузка и первичный анализ.** Файл `bank.csv` читается через `pd.read_csv`. Выводятся размерность таблицы (11162 строки, 17 столбцов), названия столбцов и информация о типах данных через `df.info()`. Проверка показывает, что пропусков нет, поэтому заполнять данные не требуется.

**3. Удаление лишнего столбца.** Из таблицы удаляется столбец `duration` (длительность последнего звонка). Он сильно связан с результатом, но становится известен только после разговора с клиентом. Прогноз нужен до звонка, поэтому использование этого признака привело бы к утечке данных и завышенной точности. Столбцов-идентификаторов (номер, имя клиента) в датасете нет, поэтому других столбцов не удаляется.

**4. Визуализация данных через график (EDA).** С помощью `groupby` считается средний баланс и среднее число контактов в разрезе профессии. Затем строится график «ящик с усами» (`sns.boxplot`), на котором сравнивается баланс клиентов, открывших депозит, и клиентов, отказавшихся. Под графиком записан аналитический вывод.

**5. Преобразование категориальных признаков.** Целевая переменная `deposit` переводится в числа: «no» в 0, «yes» в 1. Девять текстовых признаков (`job`, `marital`, `education`, `default`, `housing`, `loan`, `contact`, `month`, `poutcome`) преобразуются в бинарные колонки методом One-Hot Encoding через `pd.get_dummies` с параметром `drop_first=True`. Этот параметр убирает по одной лишней колонке у каждого признака, чтобы колонки не дублировали друг друга.

**6. Масштабирование числовых признаков и разбиение на обучающую и тестовую выборки.** Данные разделены на обучающую и тестовую выборки с сохранением соотношения классов. Масштабирование настроено по обучающим данным, после чего те же преобразования применены к тестовым. Такой порядок помогает избежать утечки информации из тестовой выборки в процесс обучения и обеспечивает более корректную оценку модели.

**7. Обучение модели.** Модель случайного леса обучена и проверена на тестовых данных. Полученные метрики позволяют оценить, насколько хорошо она определяет вероятность открытия депозита, однако качество прогноза следует рассматривать по нескольким показателям, а не только по доле правильных ответов.

**8. Оценка качества.** По тестовой выборке строится прогноз (`predict`), а точность считается метрикой `accuracy_score`. Результат: accuracy около 72,5%.

## Выводы

- **Финансовое положение:** Клиенты, принимающие решение открыть депозит, в целом имеют более высокий уровень баланса на счёте по сравнению с теми, кто отказывается от предложения.
- **Различия по категориям:** Анализ показал ощутимый разброс по уровню среднего баланса в зависимости от типа занятости клиентов (наиболее высокий уровень наблюдается у пенсионеров, тогда как у работников сферы услуг он ниже).
- **Влияние предыдущего опыта:** Результативность прошлых маркетинговых кампаний является одним из ключевых факторов: клиенты с успешным опытом коммуникации в прошлом значительно чаще соглашаются на повторные предложения банка.
- **Качество моделирования:** Модель случайного леса, обученная исключительно на признаках, доступных до совершения звонка, продемонстрировала способность уверенно разделять клиентов по их склонности открыть депозит, существенно превосходя базовое случайное угадывание.
