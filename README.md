# Лабораторная работа №1. Введение в машинное обучение и подготовка данных

## Датасет

**Bank Marketing Dataset** (`bank.csv`) — данные телефонной маркетинговой
кампании португальского банка. Каждая строка — один клиент, с которым связался
колл-центр, предлагая открыть срочный депозит.

Источник: [Bank Marketing Dataset на Kaggle](https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset)

## Бизнес-задача

Спрогнозировать, откроет ли клиент срочный депозит (`deposit`: yes/no) на
основе его анкетных данных (возраст, профессия, семейное положение,
образование), финансового профиля (баланс на счёте, наличие кредитов) и
истории контактов с банком (способ связи, месяц, число звонков, результат
предыдущей кампании).

Это задача бинарной классификации. Правильный прогноз позволяет банку заранее
отбирать клиентов с высокой вероятностью отклика и не тратить ресурсы
колл-центра на обзвон всех подряд — то есть повышает конверсию кампании при
том же бюджете.

## Краткое описание пайплайна

1. Загрузка данных, первичный осмотр (`shape`, `info`).
2. Из набора признаков исключён `duration` (длительность звонка) — он сильно
   связан с результатом, но неизвестен на момент планирования звонка, поэтому
   его использование было бы утечкой данных (data leakage).
3. EDA: средний баланс и число контактов в разрезе профессии; boxplot баланса
   в зависимости от решения клиента.
4. One-Hot Encoding категориальных признаков (`job`, `marital`, `education`,
   `default`, `housing`, `loan`, `contact`, `month`, `poutcome`), разбиение на
   train/test со стратификацией, масштабирование числовых признаков
   `StandardScaler` (обучен только на train, чтобы не допустить утечки данных).
5. Обучение `RandomForestClassifier`, оценка через `accuracy_score`.

## Основные выводы

- Клиенты с более высоким балансом на счёте заметно чаще открывают депозит
  (медиана ≈733 против ≈414 у отказавшихся) — их стоит обзванивать в первую
  очередь.
- Успешный результат предыдущей кампании (`poutcome = success`) — самый
  сильный сигнал: такие клиенты соглашаются в ~91% случаев против ~41% у тех,
  с кем раньше не связывались.
- Модель на признаках, доступных **до** звонка (без `duration`), даёт
  accuracy ≈72–73% на тестовой выборке — заметно лучше случайного угадывания
  и пригодно для приоритизации базы клиентов перед обзвоном.
