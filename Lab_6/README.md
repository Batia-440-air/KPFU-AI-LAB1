# Лабораторная работа № 6. Метод опорных векторов (SVM) и Ядерный трюк

## Данные

Страница датасета на Kaggle: https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset

Для классификации выбраны два числовых признака: `duration` — длительность последнего разговора в секундах, `pdays` — число дней после последнего контакта в предыдущей кампании. Значение −1 означает, что ранее с клиентом не связывались. Длительность разговора известна только после звонка, поэтому модель подходит для анализа завершённых контактов.

## Ход работы
Данные разделены на обучающую и тестовую выборки. Параметры масштабирования определены на обучающих данных. Отдельно обучены две модели SVM, для каждой рассчитана доля верных ответов. Для RBF-ядра найдена доля опорных векторов. Влияние штрафа C проверено на линейном ядре. На графиках показаны границы классов и опорные векторы.

## Выводы
С RBF-ядром получена более высокая точность на тестовых данных. Изогнутая граница позволила лучше разделить клиентов по результату звонка. Опорными векторами стали около половины обучающих записей. Для линейной модели изменение штрафа почти не повлияло на долю верных ответов.
