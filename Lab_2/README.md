# Лабораторная работа №2. Метод k-ближайших соседей и непараметрические методы регрессии

## Описание датасета

В работе используется датасет **Used Car Price Prediction** (файл `used_car_price_dataset_extended.csv`). Он содержит данные об автомобилях с пробегом и их цене. В таблице 10000 автомобилей и 12 признаков.

Признаки:

- характеристики автомобиля: год выпуска (`make_year`), расход топлива (`mileage_kmpl`), объём двигателя (`engine_cc`), тип топлива (`fuel_type`), марка (`brand`), коробка передач (`transmission`), цвет (`color`);
- история автомобиля: число владельцев (`owner_count`), история обслуживания (`service_history`), число зарегистрированных аварий (`accidents_reported`), наличие действующей страховки (`insurance_valid`);
- целевая переменная `price_usd`: цена автомобиля в долларах.

Столбцов-идентификаторов (номер, название модели) в датасете нет, поэтому удалять неинформативные признаки не потребовалось.

Источник данных: https://www.kaggle.com/datasets/therohithanand/used-car-price-prediction/data

## Постановка бизнес-задачи

Компания, которая покупает и продаёт автомобили с пробегом, должна быстро и объективно определять рыночную цену машины. Ручная оценка зависит от опыта сотрудника и занимает время. Необходимо по характеристикам автомобиля автоматически предсказывать его цену. Это задача регрессии: целевая переменная непрерывная.

Для решения применяются непараметрические методы: k-ближайших соседей (`KNeighborsRegressor`) и ядерная регрессия Надарая-Ватсона с гауссовским ядром. Они оценивают цену автомобиля по ценам самых похожих на него автомобилей из обучающей выборки.

## Описание пайплайна

**1. Настройка окружения.** Импортируются библиотеки: `numpy` и `pandas` для расчётов и работы с таблицами, `matplotlib` и `seaborn` для графиков. Из `sklearn` подключаются `train_test_split` для разбиения данных, `StandardScaler` для масштабирования, `KNeighborsRegressor` как модель k-ближайших соседей, `rbf_kernel` для гауссовского ядра, `mean_absolute_error` и `r2_score` как метрики качества.

**2. Загрузка данных и разведочный анализ.** Файл читается через `pd.read_csv`, выводится размер таблицы (10000 строк и 12 столбцов). С помощью `groupby` по марке считается медианная цена автомобиля, и выводятся пять самых дорогих марок: BMW (около $7155), Ford ($7055), Honda ($7051), Volkswagen ($7016) и Toyota ($6982). Разница между ними небольшая, то есть марка сама по себе слабо отличает дорогие автомобили от дешёвых.

**3. Подготовка признаков.** Все текстовые признаки (`fuel_type`, `brand`, `transmission`, `color`, `service_history`, `insurance_valid`) переводятся в бинарные колонки методом One-Hot Encoding через `pd.get_dummies` с параметром `drop_first=True`. Этот параметр убирает по одной лишней колонке у каждого признака, чтобы колонки не дублировали друг друга. Из таблицы выделяются матрица признаков `X` и целевая переменная `y` (`price_usd`).

**4. Разбиение на выборки и масштабирование.** Данные делятся функцией `train_test_split` в пропорции 80% на 20% с `random_state=42`. Пять числовых признаков (`make_year`, `mileage_kmpl`, `engine_cc`, `owner_count`, `accidents_reported`) приводятся к одному масштабу с помощью `StandardScaler`. Скалер обучается (`fit`) только на обучающей выборке, а к тестовой применяется только `transform`, поэтому информация из тестовых данных не попадает в обучение. Масштабирование важно для методов, основанных на расстояниях: без него признак с большими значениями (например, объём двигателя) заглушил бы остальные.

**5. Поиск оптимального числа соседей k.** В цикле перебираются значения k от 1 до 19. Для каждого обучается `KNeighborsRegressor`, считается средняя абсолютная ошибка (MAE) на тестовой выборке, после чего строится линейный график зависимости MAE от k. При k=1 ошибка максимальна (около $1525): модель копирует цену единственного соседа и переобучается на шум. До k=5 ошибка быстро падает (около $1105), затем снижается медленно и выходит на плато около $1040–1050 при k от 15 до 19. Для дальнейших шагов выбрано k=5: это точка, после которой дальнейшее увеличение числа соседей почти не улучшает качество, а сама модель остаётся достаточно гибкой.

**6. Сравнение метрик расстояния Минковского.** При k=5 обучаются две модели: с евклидовым расстоянием (`p=2`) и с манхэттенским (`p=1`). Евклидово расстояние показало результат лучше: MAE около $1103,79 и R² = 0,75 против MAE около $1156,94 и R² = 0,73 у манхэттенского.

**7. Ядерная регрессия Надарая-Ватсона.** Метод реализован вручную. Для каждого тестового автомобиля через `rbf_kernel` считаются веса всех обучающих автомобилей: чем автомобиль похожее, тем вес больше. Веса нормируются так, чтобы их сумма равнялась единице, и прогнозом становится взвешенное среднее цен обучающих автомобилей. Гиперпараметр `gamma`, который задаёт ширину окна, перебирается по 30 значениям от 0,01 до 10 (сетка `np.logspace`). Лучшей считается `gamma`, при которой R² максимален. Получилась `gamma` около 1,49, R² = 0,77, MAE около $1063,84.

**8. Визуализация результата.** Строится график «Реальные значения против предсказанных» для лучшей модели (ядерная регрессия) с красной диагональю, на которой предсказание равно реальной цене. Чем ближе точки к диагонали, тем точнее прогноз.

## Выводы

- Увеличение k сначала резко снижает ошибку, а после k=5 почти не помогает. При k=1 модель переобучается, при слишком больших k цена усредняется по всё менее похожим автомобилям. Значения около 5 дают хороший баланс между смещением и разбросом.
- Евклидово расстояние подходит для этих данных немного лучше манхэттенского (R² 0,75 против 0,73).
- Ядерная регрессия Надарая-Ватсона с гауссовским ядром оказалась лучшей из всех моделей: R² = 0,77, MAE около $1064. Она не отбирает фиксированное число соседей, а учитывает все автомобили с весами, поэтому прогноз получается более гладким.
- На графике «реальные против предсказанных» точки собираются вдоль диагонали, то есть модель в целом верно оценивает уровень цен. Разброс заметно растёт для дорогих автомобилей, самые дорогие модель занижает, а у самых дешёвых цену завышает. Это типичное поведение методов, которые усредняют цены соседей.
- Модель объясняет около 77% разброса цен при средней ошибке около $1064. Для бизнеса это означает, что её можно использовать для быстрой предварительной оценки автомобиля при приёмке или размещении объявления: компания получает ориентир по цене за секунды, а эксперт проверяет только сложные и дорогие случаи. Для окончательной цены самых дорогих автомобилей результат стоит уточнять вручную.
